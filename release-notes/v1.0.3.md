这次是修 bug：内置插件 `qqbot-guard` 在手机上一直没真正生效。

- **原因**：guard 启动时要先定位 `@tencent-connect/dsh-qqbot`，而候选路径里没有 profile 布局
  （`/root/.dsh/profiles/web/node_modules/@tencent-connect/dsh-qqbot`），于是一步就退出——
  关键词唤醒、群历史附件、表情还原全部静默失效，日志里只有一句「没找到 @tencent-connect/dsh-qqbot」。
- **现在**：guard 从自己的安装位置反推 profile 的 `node_modules`，再按 Node 规则向上找，
  并覆盖 `$DSH_HOME/profiles/*`、插件市场平铺布局和 pnpm 的 `.pnpm` store。
  `DSH_HOME` 没设、cwd 不是 profile 目录，都不再影响定位。
- **更好排查**：找不到包时，日志会列出「试过的每一处路径」，并直接写明补丁不会生效，
  不用再靠猜。
- **不用再手写路径**：`cordis.patch.yml` 里的 `qqbotPackage` 不再是必需品；之前手动加过的
  可以删掉（留着也仍然有效，作为显式覆盖）。

装好 qqbot 后，群里发 **大肥鱼**、**肥鱼** 或 **鱼鱼** 就会叫醒助手；开关仍在
`/root/.dsh/qqbot-guard.json`。
