这版主要解决三件事：启动慢、装完就崩没人知道、APK 太大。

- **冷启动从 21.7 秒降到 8–9 秒**：把 dsh 加载模块时的路径解析结果缓存下来，
  之后启动直接命中，绕开 proot 下最慢的 stat/realpath。缓存只覆盖镜像内的 `/opt`，
  插件目录不缓存；更新镜像时会自动清空。
- **升级后第一次启动会慢一些**：需要重新解压镜像（约 15 秒）并重建一份解析缓存，
  这一次大约 40 秒，之后就回到 8–9 秒。
- **启动失败会自动重试**：间隔 1/2/4 秒，10 分钟内失败 3 次就停下并发通知，
  点通知可手动重试，不会无限重启。
- **崩溃后能查原因**：控制面板新增「诊断」，可以看到每次启动各阶段耗时、
  上次退出原因和最后几行引擎日志；引擎日志会轮转到 `harness.log.1`。
- **更新更可靠**：检查更新改为读 release 里的 `update.json`（带 sha256），
  下载完先校验再安装；清单拉不到时回退到 GitHub API。
- **更省电，但 qqbot 行为不变**：不再一启动就永久持有唤醒锁，改成按需持有；
  插件可以领租约（`/lease`），有租约时才保持唤醒；空闲停机默认关闭（`/idle`）。
  检测到 qqbot 配置启用时仍会保持常驻，和旧版一致。
- **APK 从 351 MB 降到 261 MB**：镜像做了无损裁剪（类型声明、source-map、测试、
  其他平台的预编译产物），并改用 gzip -9；Office 和语音能力都还在。
- 清掉了 profile 里残留的旧 qqbot 插件，修掉一处会让启动直接失败的 profile 清单解析问题。

小米/HyperOS 用户如果发现灭屏后启动很慢，是系统把唤醒锁判成了 DISABLED，
给 App 打开「自启动 / 后台弹出」权限即可。
