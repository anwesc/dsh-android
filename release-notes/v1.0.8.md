这版是一个小修复：解决了「配置了自建/中转模型端点，但对话一直失败」的问题。

- **容器现在继承手机的 DNS**：之前容器里写死的是公网 DNS（223.5.5.5、119.29.29.29），
  解析不了公司内网或局域网里的模型地址（返回 NXDOMAIN），请求在发出前就挂了，
  dsh 只会报 `DeepSeek Messages transport failed`。现在启动时读取手机当前网络的 DNS，
  写一份 `resolv.conf` 绑进容器；换 Wi-Fi 后下次启动会自动更新。
- **不再反复报旧插件缺失**：profile 的 `dependencies` 里残留的 `@tencent-connect/dsh-qqbot`
  会一并清掉，启动日志不再刷 `Cannot find package '@tencent-connect/qqbot-connector'`。
- 新增两个诊断接口：`GET /log` 看引擎日志末尾，`GET /net` 分别从 App 和容器里
  探测模型端点（状态码 + 响应片段），排查网络问题时不用再猜。

和 1.0.7 相比没有其他行为变化；已经是最新版的用户，如果模型用的是官方地址，不升也不影响。
